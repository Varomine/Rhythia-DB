⚡ What Can RhythiaDB Do?

Built for maximum speed, privacy, and seamless music synchronization.

Direct Folder Sync (Zero Memory Limits)

Uses the modern browser File System Access API to stream map files directly into your local folder. Download Rhythia's entire 9,460+ map catalog without browser crashes!

Flexible Batch Downloader

Filter beatmaps by Ranked, Unranked, or Qualified categories and download in customizable batch sizes (50, 100, 200, 500 maps) or split ZIP archives.

100% Private Library Checker

Drag and drop your local songs folder or ZIP archive. RhythiaDB deeply inspects map IDs and hashes in memory to find missing maps and download them with 1 click.
